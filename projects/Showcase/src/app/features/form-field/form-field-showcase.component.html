Form Field

dzi-form-field is a component used to wrap form controls. It provides a common container for elements like labels, hints, and error messages.

Status & Validation

The form-field automatically coordinates colors for labels and hints based on the input status. Native states like error are handled by the library, while others like success can be applied via custom classes.
